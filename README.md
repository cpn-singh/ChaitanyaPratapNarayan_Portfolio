# Chaitanya Pratap Narayan — Developer Portfolio

Personal 3D interactive portfolio of **Chaitanya Pratap Narayan (CPN)** — Python Full Stack & Frontend Developer.

## Overview & Technical Highlights

- **Backend & Core Architecture**: Python 3, Django, Django REST Framework, PostgreSQL, MySQL, JWT Authentication, RESTful APIs
- **Frontend & Creative Engineering**: React.js, Next.js, Vite, Tailwind CSS, Three.js / WebGL, Interactive Shaders, 60fps animations
- **Featured Projects**:
  - **U-Learnez**: Interactive EdTech web application (React, Next.js, Tailwind CSS)
  - **SYLVRA Clean Power Grid**: 3D telemetry national radar grid (React, Three.js, WebGL)
  - **Task Management Command Center**: Kanban-inspired productivity suite (React, State Architecture)
  - **Library Management System**: Secure full-stack platform (Django REST Framework, React, PostgreSQL/MySQL)
  - **CarCraft**: Automotive discovery marketplace & dealer hub (Django REST, React, Vite)
  - **LoanWise**: AI lending & risk management ecosystem with 3D amortization simulators (React, Three.js)

## Running Locally

```bash
npm start
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
